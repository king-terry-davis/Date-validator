## Date Validator in C

This is a simple C program that validates a date entered by the user in D/M/Y format. The program checks whether the date is valid according to standard calendar rules, including leap year handling and month-specific day limits.

### Features

- Validates day, month, and year values.

- Checks leap year rules for February.

- Handles months with 30 and 31 days.

- Provides clear feedback for invalid dates.

### Requirements

- A C compiler (e.g., gcc or clang)

- Basic knowledge of terminal/command line usage to compile and run the program
